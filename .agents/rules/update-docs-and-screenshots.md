# Update Documentation and Screenshots After UI Changes

Whenever you finish a coding task that modifies the UI, tray icon, or user-facing behavior of `AntigravityQuotaTray`:
1. If anything in the interface, layout, or tray icon changed, capture and update the corresponding screenshots in `docs/` (e.g., `docs/screenshot.png`, `docs/tray.png`, `docs/tray-number.png`).
2. Update `README.md` (and any other relevant documentation) if features, settings, UI descriptions, or behavior changed.
